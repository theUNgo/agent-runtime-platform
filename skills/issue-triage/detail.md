# Issue Triage Workflow 详情说明

## 能力定位
这个 Workflow Skill 会把问题排查过程拆成几个明确步骤，输出结构化步骤摘要，适合在正式执行工具前做“先分析、再行动”的预处理。

## 当前步骤
1. 收集问题上下文
2. 检查附加输入
3. 生成下一步建议

## 推荐输入
- 用户问题原文
- 附加输入 JSON
- 与问题相关的工作区上下文

## 典型输出
- workflowSummary
- 每个步骤的 renderedInstruction
- 结构化的 steps 列表

## 注意事项
- 当前版本不会直接执行脚本或外部工具
- 结果更适合作为后续 planner、模型整理或人工确认的输入
